Getting Started ​

Requirements ​

  • Node.js 20.19 or newer
  • npm

Install ​

bash
git clone https://github.com/tuandds/colony-flow-sand.git
cd colony-flow-sand
npm install

Scripts ​

CommandWhat it does
npm run devStart the game dev server at http://localhost:8080 (level editor at /editor.html)
npm run buildType-check and build the game into dist/
npm run previewServe the built game locally
npm run docs:devStart the docs dev server
npm run docs:buildBuild the docs into docs/.vitepress/dist/
npm run build:siteBuild the full Pages site (landing + demo + docs) into _site/

Testing on a phone ​

Run npx vite --host, then open the printed network URL on a phone on the same Wi‑Fi.
